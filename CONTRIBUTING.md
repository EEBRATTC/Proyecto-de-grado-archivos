# Contribución

1. Cree una rama local con un nombre descriptivo.
2. Verifique que el cambio no incorpore datos privados, secretos, binarios no autorizados ni resultados individuales.
3. Documente origen, autoría, licencia y autorización del material nuevo.
4. Solicite revisión humana mediante pull request.
5. Requiera aprobación antes de fusionar o publicar.

Los cambios correlativos deben tramitarse por separado en el GitHub privado de scripts o en el GitLab privado de datos y resultados, según corresponda. No se aceptan cambios metodológicos implícitos ni archivos de terceros sin autorización documentada.
