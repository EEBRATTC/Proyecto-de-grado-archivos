# Estructura de repositorios

## GitHub público

Contiene documentación, manuales, arquitectura, dependencias, preparación de descargas, citación y una selección de evidencia agregada. Excluye scripts, CSV crudos, scores, encuesta individual, auditorías completas y resultados por participante.

## GitHub privado de scripts

Contiene únicamente los scripts Python definitivos de los Anexos F y G, dependencias detectadas e instrucciones de ejecución y reproducibilidad del software. No contiene datos ni resultados. Su URL no se publica y el acceso es controlado por los autores.

## GitLab privado de datos y resultados

Contiene los datos EEG de ambas etapas, `scores.csv`, encuesta, resultados completos, auditorías, figuras e inventarios. No contiene los scripts Python.

Véase también el [mapa resumido](../REPOSITORY_MAP.md).
