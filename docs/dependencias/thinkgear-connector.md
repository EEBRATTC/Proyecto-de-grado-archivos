# ThinkGear Connector

- Nombre: ThinkGear Connector (TGC).
- Titular o desarrollador: NeuroSky, Inc.
- Función: permitir la comunicación entre MindWave Mobile 2 y aplicaciones compatibles dentro de la cadena de adquisición del proyecto.
- Uso del equipo: exclusivamente académico.
- Propiedad: el equipo no desarrolló ni posee ThinkGear Connector, MindWave Mobile 2 ni los componentes de NeuroSky.

## Requisitos generales

- Equipo Windows compatible. La funcionalidad de mindApp fue comprobada por el equipo en Windows 11 Home Single Language, versión 25H2, compilación 26200.8875, sobre plataforma de 64 bits; esto no acredita compatibilidad universal de ThinkGear Connector o mindApp con otras versiones.
- MindWave Mobile 2 emparejado según documentación oficial.
- Permisos locales para instalar y ejecutar software de NeuroSky.
- La compatibilidad con otros entornos debe revisarse según la documentación vigente de NeuroSky; la comprobación registrada no constituye compatibilidad universal.

## Instalación documentada

1. Consultar la documentación y el acuerdo de licencia oficiales.
2. Obtener legalmente ThinkGear Connector desde NeuroSky o una fuente autorizada.
3. Emparejar MindWave Mobile 2 siguiendo las instrucciones del titular.
4. Instalar o ejecutar TGC según la documentación correspondiente.
5. Verificar localmente que TGC esté activo antes de iniciar `mindApp` u otra aplicación compatible.

No se ejecutó el instalador durante la organización.
