# Descripción del proyecto

## Título oficial

Esquema de trabajo para la toma de decisiones en el sector turismo de la ciudad de Cartagena, combinando lectura de electroencefalogramas con técnicas de minería de datos no supervisadas.

## Alcance confirmado

El proyecto combina señales EEG con técnicas exploratorias de reducción de dimensionalidad, normalización y análisis de concordancia. Incluye una etapa de calibración de configuraciones y otra de comparación entre resultados EEG y encuesta. El contexto geográfico confirmado es Cartagena de Indias, Colombia.

La documentación pública explica el proceso sin exponer código privado, datos crudos, scores, encuestas individuales ni resultados identificables.
